   It violates the project's own `.gitignore`. Fix:
   ```bash
   git rm --cached scripts/__pycache__/clean_pdb.cpython-313.pyc
   git commit -m "build: untrack stale __pycache__ pyc"
   ```

2. **Delete stale remote branch `copilot/explore-codebase-structure`.**
   Its commits are already merged into `main`; the branch adds noise to the
   GitHub branch picker. Use the GitHub UI or `git push origin --delete
   copilot/explore-codebase-structure` from a workstation with write access.

### Medium priority

3. **Decide what to do with uncommitted local edits.**
   `protocols/cosmotherm-screen/screen-mixture.tmpl` and
   `scripts/cosmotherm_postprocess.py` have ~98 lines of uncommitted changes
   in the local working tree. Either commit them (if they are stable) or
   stash them — leaving them as drift makes the next audit harder to read.

4. **`.gitignore` additions.**
   - Add `.claude/` (currently only `.claude/audit-reports/` is ignored, so
     `.claude/agents/` and `.claude/settings.local.json` surface as
     untracked on every `git status`).
   - Add `docs/` *or* explicitly ignore `docs/COSMOtherm_Manual.pdf` if you
     plan to track other docs (e.g. these audit reports). The vendor PDF is
     large and not redistributable; it should never be committed.
   - If audit reports under `docs/audit/` *should* be tracked, add a positive
     `!docs/audit/` rule.

### Low priority / informational

5. **Tracked PDB outputs may be over-committed.** `molecules/lysozyme/lysozyme_pH4.5.pdb`
   (334 KB) and the `*_clean.pdb` files are products of `prepare_molecule.py`
   running on the upstream `2LYZ.pdb` / `1SHO.pdb`. They are essentially
   "frozen reference geometries". This is fine as a reproducibility anchor,
   but if the protonation pipeline output is expected to change (e.g.
   PROPKA-corrected geometries supersede them), they will start to drift
   from what the scripts actually produce. Consider moving them under
   `molecules/<mol>/reference/` (which `.gitignore` already keeps tracked
   via the `!molecules/*/reference/` exception) so the intent is explicit.

6. **No tracked compute artifacts.** Aside from the one pyc file, the
   `.gitignore` is doing its job — no `.cosmo`, `.ccf`, `.out`, `.err`,
   `mos`, `slurm-*.out`, `*.xyz`, or `*.slurm` files are tracked. The
   cleanup commits `4c89644` + `7850b28` (xyz untracking) and `1b4e18f`
   (audit-2026-05-11 followups) successfully closed off the most common
   accidental-commit pathways.

7. **Total repo size is small** (~1 MB of tracked content, 56 files). No
   action needed on size — the repo is healthy for a chem-pipeline project
   of this scope. The bulk of the bytes (831 KB / 82%) is in `molecules/`,
   which is expected.
